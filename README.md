# 🎨 QR Studio - Advanced QR Code Generator

A comprehensive, modern QR code generator with advanced customization options, built with vanilla JavaScript and Tailwind CSS.

## ✨ Key Features

### 🎯 **Multiple Data Types**
- **Text/URL**: Standard text and web links
- **WiFi Networks**: Generate QR codes for WiFi connections
- **vCard Contacts**: Business cards and contact information
- **Email**: Direct email composition
- **SMS**: Text message initiation
- **Phone Numbers**: Direct calling

### 🎨 **Advanced Styling**
- **Gradient Colors**: Linear gradients with customizable angles
- **Color Themes**: Full color customization with hex display
- **Style Presets**: Square, Rounded, and Dots patterns
- **Custom Margins**: Adjustable whitespace around QR codes
- **Real-time Preview**: Instant updates as you customize

### 🖼️ **Logo Integration**
- **File Upload**: Support for JPG, PNG, SVG logos
- **Smart Positioning**: Automatic centering with background
- **Shape Options**: Square or circular logo masks
- **Size Control**: Adjustable logo size (5-40% of QR code)
- **Background Protection**: Automatic contrast enhancement

### 📐 **Export Options**
- **Multiple Formats**: PNG, JPG, SVG downloads
- **Resolution Control**: From 300px to 4K (4000px)
- **Custom Dimensions**: User-defined width/height
- **Bulk Generation**: Create multiple QR codes simultaneously
- **Batch Download**: ZIP archive for bulk exports

### 🌙 **Modern UI/UX**
- **Dark/Light Mode**: Automatic theme detection with toggle
- **Responsive Design**: Mobile-first approach
- **Glass Morphism**: Modern frosted glass effects
- **Smooth Animations**: Fade-in, slide-up transitions
- **Toast Notifications**: User-friendly feedback system

### 💾 **Preset System**
- **Built-in Themes**: Classic, Blue Ocean, Forest, Sunset, Purple Dream, Dark Mode
- **Custom Presets**: Save your favorite configurations
- **Share Configurations**: Generate shareable links
- **Local Storage**: Persistent settings across sessions

### 📊 **Statistics & Analytics**
- **Generation Counter**: Track QR codes created
- **Download Counter**: Monitor export activity
- **Real-time Info**: Size, character count, QR version
- **Performance Metrics**: Local storage persistence

### ⚡ **Advanced Features**
- **Error Correction Levels**: L (7%), M (15%), Q (25%), H (30%)
- **Quality Optimization**: High-resolution rendering
- **Loading States**: Visual feedback during generation
- **Gradient Effects**: Advanced color transitions
- **Configuration Sharing**: URL-based preset sharing

## 🚀 **Getting Started**

1. **Open `index.html`** in any modern web browser
2. **Enter your content** in the data field
3. **Customize appearance** using the left panel controls
4. **Watch live preview** update in real-time
5. **Download** your QR code in preferred format

## 💡 **Pro Tips**

1. **High Error Correction** (H level) recommended for logos
2. **Square logos** work best for QR code integration
3. **Contrast is key** - ensure readability with color choices
4. **Test scanning** on different devices and distances
5. **Use bulk generation** for multiple similar QR codes
